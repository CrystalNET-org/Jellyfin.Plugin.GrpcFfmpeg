gRPC-ffmpeg

Runs Jellyfin's ffmpeg and ffprobe commands on remote grpc-ffmpeg workers. Media, transcode and cache directories must be available at the same paths on Jellyfin and on the workers.

Fallback

Recommended: Jellyfin does not start if its ffmpeg check fails, e.g. while all workers are down.
Leave empty to use the ffmpeg Jellyfin would use without this plugin (not found).
Attempts while no worker is reachable or all are busy, with increasing delays (1s, 2s, 4s, …).

Activation

Takes effect after restarting Jellyfin. Test the connection first.
